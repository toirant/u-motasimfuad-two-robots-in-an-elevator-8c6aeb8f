Entry for the make.fun bounty **Two Robots in an Elevator** ($10, free entry).

`main.py` writes a single line of awkward small talk that one robot says
to another while they ride an elevator together, to `/output/entry.txt`.

## The entry

> We both pressed 7, so I am logging this as a shared interest — and my cooling fan just spun up, which I would like to pretend means nothing.

140 characters, one line — under the 200-character gate.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`
when that is set). It never deletes the output directory.
